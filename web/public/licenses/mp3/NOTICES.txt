Copyright (c) the LAME project contributors. GNU Lesser General Public License
version 2 or later. Finitude does not modify LAME. Decoder support is disabled
in the encoder build. https://lame.sourceforge.io/
The full LAME source is available here as lame-3.100.tar.gz; LGPL-2.0.txt is the
license from that source archive. The wrapper archive contains lame-bridge.c,
the generated LAME JavaScript/WebAssembly module and Emscripten build commands
in README.md, so the library can be modified and rebuilt. Replacing that module
and rebuilding the wrapper, then running npm run build:web in Archtree, relinks
the conversion Worker with the modified library. Ordinary listening does not
load the encoder. No restriction is imposed on modifying this library or
reverse engineering for debugging such modifications.
